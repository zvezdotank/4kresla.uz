# Четыре кресла — 4kresla.uz

Сайт парикмахерской на первом этаже девятиэтажки, Ташкент, ул. Сайхун, 166.
Одна страница, без сборки: открывается `index.html` как есть.

```
index.html            вся страница
assets/css/tokens.css токены дизайн-системы (цвет, шрифт, отступы) — из handoff Claude Design
assets/css/site.css   вёрстка страницы
assets/js/app.js      меню, подсветка навигации, лайтбокс галереи
assets/img/           фотографии
tools/map.py          рисует карту по данным OpenStreetMap и вписывает её в index.html
design-system/        исходный handoff-бандл Claude Design (справочник, в сайт не подключён)
```

## Что править чаще всего

- **Цены** — блок `<div class="prices">` в `index.html`.
- **Телефон** — ищи `+998903579540` (шапка, герой, полоса «Только по записи», контакты)
  и `+998 90 357-95-40` в видимом тексте.
- **Часы работы** — блок контактов и `openingHours` в микроразметке в `<head>`.
- **Цвета и шрифты** — только `assets/css/tokens.css`, в `site.css` захардкоженных цветов нет.

## Мастера

Блок «Наши мастера» — заглушка: четыре карточки без фотографий, имена кроме Евгения
не заполнены. Разметка готова, нужно заменить `master__frame--empty` на
`<div class="master__frame"><img class="photo" src="assets/img/master-…jpg" …></div>`
и вписать имена. Снимать у окна, дневной свет, без вспышки, по пояс.

Фотографии в герое, широкой полосе и галерее — временные, вырезаны из чужого макета.
Их нужно заменить на съёмку самой парикмахерской, иначе сайт обещает не то место.

## Карта

Карта — инлайновый SVG, нарисован по данным OpenStreetMap в цветах сайта, ничего
не грузит с чужих серверов. Перерисовать после смены адреса:

```
python3 tools/map.py
```

Скрипт кэширует ответ Overpass в `tools/osm.json` — чтобы перекачать данные заново,
удали этот файл. SVG вписывается в `index.html` между `<!-- map:start -->` и `<!-- map:end -->`.
Требование лицензии OSM: подпись «© OpenStreetMap» под картой убирать нельзя.

## Проверено

Горизонтальной прокрутки нет на 320, 375, 390, 480, 768, 900, 1024, 1280 и 1440 px.
Шрифты — Google Fonts (Oswald, PT Sans, Marck Script), иконки — инлайновый SVG-спрайт,
внешних скриптов нет.
