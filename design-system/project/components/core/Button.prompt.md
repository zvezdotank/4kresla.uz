Brass uppercase CTA — use for booking actions, one primary per view.

```jsx
<Button size="lg">Записаться онлайн</Button>
<Button variant="ghost">Смотреть галерею</Button>
```

Variants: `primary` (brass fill, default), `outline` (brass hairline, fills on hover), `ghost` (for dark photo overlays), `dark` (near-black). Labels are always uppercase with wide tracking; keep them 2–3 words.
